## 自动化的边界

- 定时采集器获取最新文章及 RSS 配图，构建器按文章 URL 取图、缓存，部署后展示；浏览器刷新不即时抓图。
- 成功缓存 7 天、失败缓存现已调整为 30 分钟，新文章 URL 或 RSS 图片地址变化触发新一轮获取。规则升级使旧图缓存失效。
- 自动过滤主页通用分享图、头像、导航图片、推荐区重复配图，以及可识别的 GitHub 周报头图期号冲突。
- 原站仍可能提供错误元数据、删除图片、改版，或复用无法从文件名识别的旧图，因此不能承诺未来每一期 100% 正确。无法确认来源或抓取失败时保留插画。

## 验证

- 25 个 Python 场景通过，包括导航头像、主页通用图、重复配图、错期期号、旧缓存失效和图片重定向到头像等场景。
- 6 个 Bun RSS 提取和元数据生成场景通过。
- 原有 69 项浏览器检查验证显示和交互，不将其当作图片语义正确性的证明。
- 当前代码尚未发布，线上自动更新行为需部署后才生效。
